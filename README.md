# LF08 – Daten systemübergreifend bereitstellen

Python-Übungen und Beispielprojekte aus dem Lernfeld LF08V2 (Daten systemübergreifend bereitstellen), erstellt im Rahmen der Umschulung zum Fachinformatiker Systemintegration (GFN).

## Inhalt

- **Werkstatt.py** — Übung zu Kapselung (Datenkapselung) und Polymorphie
- **json-xml-uebungen/** — Übungen zum Einlesen und Verarbeiten von JSON- und XML-Dateien
- **gebaeudeverwaltung/** — Beispielaufgabe Gebäudeverwaltung (Vererbung: Gebäude, Lagerhalle, Wohnhaus)
- **musikinstrumente-v1/** — Musikinstrumente-Klassenmodell, Version 1
- **musikinstrumente-v2/** — Musikinstrumente-Klassenmodell, Version 2 (Gitarre, Saxophon)
